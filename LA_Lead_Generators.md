## Classification Key

| Code | Category | Description |
|------|----------|-------------|
| WEB | Website Demo | Can be built as website interactive, no patient data required |
| PLT | Platform Feature | Requires live platform with practitioner login |
| DAT | Data-Dependent | Requires longitudinal patient data (minimum 50 assessments) |
| PHY | Physical Product | Requires manufacturing, printing, or shipping |
| MKT | Marketing Asset | Content, visuals, or materials for lead generation |
| GOV | Governance Tool | Produces compliance/regulatory documentation |
| NET | Network Effect | Improves with more practitioners/patients |
| API | Integration | Requires API, webhook, or external system connection |
| REG | Regulatory Gate | Requires MHRA/W10 clearance before deployment |

## Feature Register

### F1. Blind Spot Finder [WEB]
Practitioner selects zone they would treat first. Architecture reveals DRD designation and upstream source they missed. Creates cognitive dissonance.

### F2. Intervention Sequence Replay [WEB]
Two parallel timelines: treat wrong zone (partial improvement then regression) vs treat DRD zone (sustained improvement). 12-week simulated window.

### F3. Colleague Challenge [WEB]
Shareable URL encoding terrain state. Recipient adjusts own sliders. Split-screen comparison of two practitioners' assessments.

### F4. Pattern Recognition Cohort [DAT/NET]
